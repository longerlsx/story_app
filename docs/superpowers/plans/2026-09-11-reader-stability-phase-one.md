# 第一阶段修订计划：稳定纯阅读，收敛必要重构

状态：本轮覆盖范围已完成实现与验证，性能边界见第4节。2026-09-11 用户授权实施，基线 HEAD `8da8362`。保留既有文档改动及历史未跟踪计划。当前事实见 [当前状态](../../current-state.md)，稳定规则见 [协作约定](../../knowledge/agent-operating-agreements.md)。本文件保存已批准计划和执行记录。

## 1. 目标、前置工作与边界

顺序：**补齐 docs 稳定规则 → 保存计划并核对一致性 → 开发。** 协作约定集中补齐计划、验证准入、预算、委派和批量规则，入口删除“专项验收预算不适用”的冲突表述。800 行预算是本次新引入，不追溯适用。入口负责路由，约定负责规则，当前状态负责最新结论，计划负责执行记录。

**主类型：阅读问题修复；次类型：必要重构。主结论：在明确覆盖的输入和设备操作中，导入、连续阅读、改变排版、退出与恢复可靠，正文完整、位置符合操作意图、显示稳定，已确认阻塞得到处理。**

不变量：章节与实际页面不丢/重复正文、不裁行；导航符合输入顺序，旧计算/回调/内部换窗口不改最新目标；只保存确认位置，失败/取消/中间态不覆盖有效进度；兼容旧书/目录/进度，单本损坏及无关朗读初始化不拖垮纯阅读；保留可用测量、分页、渲染，重构对应具体问题。

排除搜索、删书、在线来源、新格式、皮肤、男声、听书服务改造；不建设数据库迁移框架、通用缓存平台或验收系统。

## 2. 开发顺序与边界

### A. 正常入口与旧数据

- 沿用 JBR、Gradle Wrapper、SDK、设备入口解决环境故障，不升级依赖/替换下载来源掩盖 TLS 问题。
- 建立当前代码的测试、正常启动、代表性阅读基线；继承未失效证据。
- 旧格式磁盘 fixture 包含 TAB 标题、非零进度、最近阅读书籍；初始化前后文件字节不变。
- 一次异步初始化恢复索引、目录、进度，开书/导入等待同一次初始化；音色预载独立按需，不作为纯阅读前提。
- 目录或源文件损坏按书报告、隔离，其他书可用。

### B. 正文、分章与持久化

- 本地选择和外部打开共用 TXT 读取、校验、导入、错误反馈；文件操作/解码/解析后台执行。
- 统一生产解码和规范化，偏移对应同一正文。只修已确认重复/错误的标题、正文起点、切分，不重写整个分章器，不按书名生产分支。
- TSV 首列/末三列/中间标题解析兼容 TAB，校验数量、序号、范围、顺序，不能静默少章。
- 保留有效旧目录、原 TXT、bookId，不自动重切旧书；失败导入不留可打开半成品。
- hydrate 只读；旧进度被拒绝后不写盘；新进度与最近阅读书籍串行一次提交。目录/设置/进度同目录临时原子替换，新导入最后提交元数据。
- 正文首次访问按书加载，最多缓存两本，同书并发读取合并，全局锁内不 IO，不预载整个书架。

### C. 位置与连续操作

保留 `ReadingAnchor(chapterIndex, charOffset)`，集中管理确认位置、待到达目标、带编号定位请求；排版标识只包含影响布局的内容/参数。

| 操作 | 固定语义 |
| --- | --- |
| 连续前后翻页 | 按输入顺序从待到达位置推进，不从滞后画面重复出发、不仅保留最后方向 |
| 目录 | 覆盖此前未完成导航，后续翻页从目录目标继续 |
| 字号/行距/段距 | 保留最新目标文字，待解析翻页按输入时排版确定目标，再映射新排版 |
| 主题/亮度 | 只更新显示，不定位、不使分页失效 |
| 内部换窗口 | 同页身份，不算用户翻页、不重复提交 |
| 取消/旧结果 | 取消不翻页，旧结果不修改目标或保存 |

边界逐条处理，书首“上一页、下一页”到第二页，不能净加方向。滚动用真实段落布局/文字行/原文偏移替代整章高度比例。分页恢复包含目标文字；滚动目标行对齐阅读区顶部，书尾受最大偏移限制时完整可见；空白偏移取同章后续可见文字，章末取最后可见文字。

删除常规重复跳章首/补偿滚动，新请求覆盖旧显示任务；后台/返回保存不可变快照。失败/取消有终态，布局等待默认前台累计 10 秒超时、后台暂停；保留有效页面/进度，支持重试/返回，无首屏则错误态，不无限等待或写零页。

### D. 分页、跨章与控件

- 保留按行分页、页底复查、原文区间、统一渲染，不以优化删除完整性保护。
- Pager 窗口：上一章末页｜当前章各页｜下一章首页；点击/滑动共用路径。
- 跨章复用结果，同页身份无动画换窗口，准备时保留内容、不闪空页或章首。
- 三章分页从组合期串行重算分离：目标优先、邻章随后，连续排版合并，过时计算取消/丢弃，按章节和排版复用，不全书预分页。
- 测量器线程安全，不跨线程共享 UI 可变测量实例。新路径稳定后删除旧叠页动画和补偿状态。
- 短按单入口，拖动/取消/长按消费后不松手翻页；面板不穿透，控制栏不改变正文尺寸。
- 系统返回先关面板否则回书架；顶栏回书架；退出共用进度保存。

保持 `BookRepository` 方法/语义；`AnchorStore` 增加组合保存、兼容旧键；已有朗读起点/跟随/手动通知接共同定位，不改队列/音源。

## 4. 分页性能口径与冻结

不预设两帧 p95/100ms 门槛，不自动必跑 20 次/15 分钟；重复次数服务明确问题。

修改分页调度前冻结：设备/系统/刷新率（模拟器含宿主条件）；代码/APK/buildType；文本、章节字符/段落数、排版、方向；操作序列、冷热状态、次数、统计窗口和异常处理。debug 定位，同一种非调试构建前后比较，不混数据。

只测首次排版（开书整体、加载、分页、稳定首屏分开）、连续字号（最后输入至稳定、过时计算、帧）、邻章准备/交接（计算、复用、显示分开）。优先现有 Android Studio 系统轨迹和 ADB 帧数据，必要局部方法采样区分行测量/页底复查；跟踪开销不当体验数值。

小样本校准后写入指标、波动、阈值并冻结，再改实现，不能事后放宽。不能可靠测得的分位数不用，不建设 benchmark 平台。默认可用模拟器验证行为/同环境比较，未测小米不声称实机性能。
