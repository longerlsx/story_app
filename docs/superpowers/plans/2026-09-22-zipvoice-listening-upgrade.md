# ZipVoice 单音色与听书交互实施计划

日期：2026-09-22。状态：实现与本轮验收完成。用户本轮目标优先于旧方案：**仅模拟器验收，不安排、不等待真机；不声称小米性能通过。** 设计源为[已确认讨论稿](../specs/2026-09-22-listening-controls-and-voice.md)，稳定规则见[协作约定](../../knowledge/agent-operating-agreements.md)。

## 目标与停止线

主类型：功能改进；次类型：关联可靠性修复。必要重构只服务于新音源和听书操作。

交付结论：正式 App 内置 ZipVoice-Distill 及 `leijun-1` 参考声音，仅一个音色，离线完成实际1×／2×小说播放；独立听书面板和页顶起读符合用户操作意图，关联后台、恢复、定时及旧数据兼容在指定模拟器有直接证据。

不变量：正文与有效进度不丢；新开朗读固定操作时页顶正文行首，暂停／焦点恢复／自动跨章不重设起点；停止或过期计算不得复播；设置立即保存且下一语音单元生效；面板不改正文布局、不穿透、不加成功提示；最终 APK 不打包两套音源、不依赖运行时下载。

不重新展开选型，不训练、不建音色管理／缓存／验收平台，不升级无关框架，不增加全书时间轴或起点选择。功能、受影响回归、实际音频和一次独立实现检查完成，实质问题收口，即结束；真机及固定30分钟长测不设为本轮门槛。

## 工作基线与顺序

当前检出目录保留上一轮视觉改版及文档的未提交修改，以其为工作基线，不回滚、不自动清理其他历史文件。沿用 JBR、Gradle Wrapper、SDK、sherpa-onnx 1.13.8 和现有 Pixel_8 AVD；构建、模型发布与设备测试由主代理串行协调。

1. 固定资源与接口：复用 Downloads 中试听模型和已确认参数（Distill INT8、4步、雷军参考录音／准确文字），核对 Android AAR 的真实接口；更新可复现资源准备脚本，避免两个模型同时打包。
2. 尽早验证新引擎：先让既有实际引擎测试和真实 AudioTrack 路径工作，记录首声、生成／音频时长及1×／2×。明确不足先定位对应生成、分段或播放问题，不用换声音、联网或降低速率掩盖。
3. 并行完成独立面板组件；主代理接入 ReaderScreen 的状态、页顶起读、长按仅开设置和设置迁移。保留播放服务的可靠部分，删除旧起点弹窗、朗读页签、重复按钮和无用支线。
4. 用完整界面和真实小说执行代表连续序列，检查实际声音、前后章节和页顶位置；补受影响后台／焦点／定时／覆盖升级。继承未失效的纯阅读与存储证据。
5. 一次独立实现检查；处理实质问题，更新当前状态与依赖说明，交付可覆盖安装 APK 和精简证据。提交推送遵循既有授权范围。

每个新测试／命令必须回答会影响实现或通过判断的未决问题，优先现有入口；不做验证器验证验证器，不因文档整理重跑已有效的相同构建。批量先小样本校准，小说原文与完整日志不入 docs。

分工：音源代理限引擎、资源准备及其直接测试；界面代理限面板／控制组件及其测试；主代理负责 ReaderScreen、定位／设置接线、共享构建与设备。代理不得自行扩大验证门、抢跑共享构建或派生审查链；接口和必要新增验证先交主代理协调。方案审查只查实际遗漏，实施后保留一次有边界的独立检查。
